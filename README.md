# Workforce Analytics & Employee Attrition Intelligence System

## Project Overview

The Workforce Analytics & Employee Attrition Intelligence System is a data science project designed to analyze employee workforce information, identify attrition patterns, explore employee characteristics, and generate data-driven HR insights.

The project uses Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Streamlit, and Plotly.

## Business Problem

Organizations need better visibility into workforce composition and employee attrition.

This project analyzes historical employee data to help HR stakeholders understand workforce patterns, examine factors associated with attrition, and explore employee segments.

## Project Objectives

- Analyze employee demographics and departments.
- Perform data cleaning and quality checks.
- Explore salary and workforce distributions.
- Analyze employee attrition patterns.
- Perform statistical analysis.
- Build a machine learning model to explore attrition prediction.
- Segment employees using K-Means clustering.
- Develop an interactive workforce analytics dashboard.
- Present evidence-based business recommendations.

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd "Workforce Analytics Study"
```

Create a virtual environment:

```bash
python3 -m venv .venv
```

Activate it:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Place the permitted dataset in the required data directory.

## Run the Dashboard

```bash
streamlit run dashboard/app.py
```

## Run Tests

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

## Dataset Limitations

This project uses a historical employee dataset for educational and analytical purposes.

- It does not represent a live organization's workforce.
- It does not provide reliable real-time hiring trends.
- It does not directly measure employee productivity.
- Observed relationships do not establish causation.
- Model predictions are uncertain and should not be used to make employment decisions.

## Responsible Use

The project is intended for learning, workforce analysis, and demonstration.

Employee information should be handled securely. Analytical findings should be interpreted carefully, with attention to data quality, privacy, fairness, and limitations.
